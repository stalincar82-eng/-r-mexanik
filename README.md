# Моторная

Бесплатная браузерная демоверсия 3D-симулятора автомеханика. Игра запускается в браузере или как устанавливаемое Windows-приложение.

## Запуск

- **В браузере:** открой `index.html` и выбери компьютер или телефон.
- **На сайте:** [Моторная — браузерная игра](https://stalincar82-eng.github.io/-r-mexanik/).
- **Установщик Windows:** скачай [Motornaya-Setup.exe](https://github.com/stalincar82-eng/-r-mexanik/releases/download/latest/Motornaya-Setup.exe). Установщик создаёт ярлыки в меню Пуск и на рабочем столе.
- **Через локальный веб-сервер:** в папке проекта выполни `python -m http.server 8000`, затем открой `http://localhost:8000`.
- **Разработка приложения:** выполни `npm ci`, затем `npm start`. Установщик Windows собирается командой `npm run build:win` на Windows x64.

Требуется Windows 10/11 x64 и поддержка WebGL. Three.js и загрузчик включены в проект; для игры не нужен доступ к CDN.

## Управление

- `W A S D` или стрелки: ехать и поворачивать.
- `Пробел`: тормоз.
- Мышь: двигай курсор влево/вправо над сценой, чтобы поворачивать; зажми кнопку и потяни, чтобы вращать обзор. На телефоне свайп по сцене вращает обзор и задаёт направление поворота.
- Экранные кнопки газа, тормоза и поворота доступны на телефоне. Короткое нажатие газа трогает машину, удержание ускоряет.
- Кнопки **Ехать / Гараж** или `E`: переключить режим.
- В гараже нажимай **Снять / Установить** напротив найденной детали. Если GLB содержит четыре отдельных колеса, снятое колесо блокирует поездку.
- На телефоне используй сенсорные кнопки на экране.

В селекторе доступны BMW M3 GTR, Volvo S60 R 2004 года и Audi S4 2006 года. В BMW GLB есть отдельный капот; узлы колёс собраны в общий комплект, двери и багажник отдельно не размечены. В Volvo GLB есть отдельные узлы капота, багажника и четырёх колёс; двери отдельно не размечены. У Audi узел шин объединён, а капот, двери и багажник отдельно не выделены. В гараже показываются только найденные детали: их можно снять и установить, а размеченные капот и багажник — открывать и закрывать. Если части кузова объединены внутри GLB, игра сообщает об ограничении вместо имитации разборки.
